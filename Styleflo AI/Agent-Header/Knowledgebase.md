The knowledgebase is the brain of the agent, it is where the b2b user trains the agent with personalised data.  Currently the b2b admin can;
1. Scan a website - by entering a domain the user can select 'find sitemap' and if one exists, the page will display the list of available urls that can be selected to be scanned, this allows for 20 pages at a time, and allows users to prioritise pages should their data allowance be running out.  The user can also select for pages to be re scanned on a selectable timeslot (Daily, weekly, 2 weekly) should pages change frequently
2. Upload a document - users can upload most common doc types up to 20mb in size, this allows for price lists, general data and other data to be uploaded.
3. Open text area - users can type directly into the field, this is ideal for 'one off's' such as a sale for today only.
There is also an Agent Rules area that allows users to create rules that the agent MUST follow, an example of this could be, using the agent to pre-select interview candidates, a rule might look like;
- If a customer is enquiring about a role with us, before you can pass the customer details to the interviewing manager you must get the customer to: a) confirm that they are eligible to work in the UK. b) what qualifications they have. c) what experience they have.
or
- If a customer asks if we are GCPR compliant you must inform them that we are compliant and full details can be found in our privacy policy on the website.
