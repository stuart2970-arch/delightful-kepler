# StyleFlo Project Rules & Directives

## 1. Start of Session Synchronization
At the beginning of each session, you MUST run a check (e.g. `git pull` or `git fetch` and status checks) to confirm if any changes have been made to the repository on another device. Read the latest content of `README.md` to establish the correct current state.

## 2. End of Session Documentation
At the end of each session, you MUST document all changes made to the codebase in the root `README.md` file under the "Session Enhancements & Runbook" section.
